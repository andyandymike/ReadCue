## Reproduce the data audit

The three scripts use the Python standard library (Python 3.9+). From the repository root:

```sh
python research/ugtphon-2026-09-28/audit_data.py
python research/ugtphon-2026-09-28/audit_supplement.py
python research/ugtphon-2026-09-28/audit_filtered_lookup.py
```

The first script obtains six public English/Vietnamese JSON files, totaling approximately 38.3 MB, from pinned UGTPhon commit `da2b3ee84e15e98ba48b388f7ee291ba4c3579b2`. It checks byte counts and Git blob hashes and records SHA-256 hashes. It also reads current upstream metadata; GitHub API/network availability is required. Raw files go into the ignored `data/` directory beside these scripts. The later scripts read those local files.

Running the scripts regenerates the JSON reports here. Review any changes rather than treating a changed report as a new model result. The Markdown analysis is a dated human-readable interpretation, not regenerated by the scripts.

The archived results were produced before repository initialization. Import did not rerun downloads or training. Original datasets remain subject to their [source licenses](../../docs/DATA_AND_LICENSES.md); this repository does not redistribute the sentence-level corpus.
