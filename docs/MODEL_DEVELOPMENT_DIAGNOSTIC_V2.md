## 复现

使用原模型环境与合法持有的本地数据，所有输出目录须全新。工具不随源码打包训练数据或权重。

```sh
python tools/diagnose_model_development.py prepare \
  --dataset /path/to/v2/dataset --adapter /path/to/v2/train \
  --task-config configs/model_task_v1.json --output /path/to/new-diagnostic
python scripts/run_model_experiment.py predict \
  --project /path/to/ReadCue --model-dir /path/to/qwen3-0.6b \
  --task-config configs/model_task_v1.json \
  --inputs /path/to/new-diagnostic/inputs.jsonl --adapter /path/to/v2/train \
  --output /path/to/new-diagnostic/predict --budget-root /path/to/new-diagnostic
python tools/diagnose_model_development.py score \
  --prepared /path/to/new-diagnostic --prediction-run /path/to/new-diagnostic/predict \
  --output /path/to/new-diagnostic/scoring
```

`preparation.json`绑定准备文件；`predict/run.json`绑定实际推理输入、任务和adapter；`scoring/summary.json`与逐例记录保存离线诊断。对不匹配输出的后续审查独立记录，不覆盖原始参考或自动分数。

## 下一版范围决定

当前优先交付可复现的 v2 研究候选；不因已有模型缺陷而无限推迟研究交付。下一版的研究问题收窄为：**能否学会已经存在的转换对照，同时降低字面内容误改？**

- 优先诊断首字母缩写／网络缩略语、数量与编号、百分数，以及引用／变量／字面表情的保留边界。训练集中已经有失败实例，不能一概归因为缺样本。
- 4项政策未决作为单独勘误候选，在形成新监督版本前确定边界；原166/53、参考与v2成绩保持原样。验证角色不搬入训练，45条已看评测仅作回归，不复制其答案或换词改写进训练。
- 先设计固定数据的单因素拟合对照，再判断是否补覆盖；不同时增加数据、改提示、扩大模型和追加训练次数。此次诊断无法决定哪项优化参数有效，不预先宣称具体修改会改善。
- 下一轮保持中文整句输入输出和同一0.6B基座，延续本地最多3轮、100次更新、2小时、5GiB与费用0的边界。若开展新泛化测量，须另行冻结评测并在训练／选点前隔离参考；不能复用本报告分数作为未见结果。

本轮已完成诊断与候选打包，没有启动 v3 训练或新增 v3 权重。此范围决定限定后续实验，不把尚未做的优化实验写成已有结果。
