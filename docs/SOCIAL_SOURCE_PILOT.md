# 中文社交来源小样本比较

日期：2026-09-29。状态：完成获取、逐条助手筛查及来源核验；没有生成标准读法，没有模型推理、训练或付费调用。本报告是数据审计，不是 ReadCue 模型结果，也不是人工审核 benchmark。

## 结论

四个来源共筛查 **143 条来源记录，精确去重后 125 条原文**。CSM 与 RedTrans 更贴近社交表达，但两份全集有 **1,070 条完全相同的中文原文**，不能把它们当成独立数据源叠加。WildChat 本批以提问、指令为主；Emacs China 能取得讨论上下文，但技术交流偏差明显。

按当前文本规范化任务复核，去重后有 **10 条明确数字或连接符处理点、12 条处理策略待定、94 条保留对照、9 条超出本轮短文本范围**。这不证明只有 10 条有研究价值：保留对照用于检查模型是否擅自展开缩写、解释网络词或改写型号。也不证明这 10 条是现有系统的错误，尚未运行模型。

本轮支持继续制作真实来源的小型验证集，不足以直接决定训练。先对候选读法和保留策略作人工复核，再比较现有规则及小模型，才能判断新增训练的价值。

## 获取范围与可复现性

统一排序使用 UTF-8 文本的 SHA-256，前缀为 `readcue-social-v1` 加一个 NUL 字符。去重采用精确原文，不先删空白或改 Unicode。超过 300 字的整条样本计入超范围，不截断后替补。已有来源材料是公开探索数据，不称为盲测。

- **CSM**：固定版本 `c22b83b9f9279c1b7cf20b3e2d5c268359674999`，复用之前保存的两份中文源文本文件；1,183 条 fun posts 与 998 条唯一 snippets，合计 2,181 条唯一原文。各取哈希排序前 20 条，只用 `source` 字段筛查，不用译文或俚语标签倒推判断。
- **RedTrans**：固定版本 `8d0c5097d358e9b72bf663baa2beacf07309ed55`，通过 GitHub API 取得原文件并核验 Git blob 和 SHA-256。仅保留 `src_lang=zh` 的 1,428 条唯一中文原句，按哈希排序取 40 条；英语源句的中文翻译不计入。
- **WildChat**：中文过滤接口返回 HTTP 500，保留失败记录；改用官方 rows API，取得前 300 条多语言记录，从中取每段对话第一条满足语言标记及至少两个汉字的用户消息，精确去重得到 62 条，再哈希排序取 40 条。三次响应的 `X-Revision` 均为 `c827c6df8fcf008219ffaffa4d1dd77491099367`，与固定卡片和许可版本一致。抽样为时间顺序前缀，不代表当前全库；所选 40 条均无截断或消息脱敏标记。只有 3 条带先前轮次，AI 回复仅存作背景，不作目标或标签。派生样本未纳入用户位置、IP 哈希或浏览器标识。
- **论坛**：固定一次 RSS 快照的 30 个主题，按主题 ID 哈希选 8 个；7 个成功、1 个 HTTP 503，未替换或扩抓。成功主题完整返回 39 条合格普通帖子，按每主题最多 5 条得到 23 条。共 10 次匿名请求，保存正文、楼层、时间、主帖及可取得的直接回复对象。HTML 提取排除代码块、引用块及站点自动生成的链接预览；保留行内代码、可见链接文字和表情。原始响应未改，转换和派生文件旧新哈希单独记录。两个样本明确引入模型分析，不能把论坛账号发帖等同于真人原创。

WildChat 获取变更保存在 `protocol-amendments.json`；原 `protocol.json` 仍保留。四来源 143 条映射均重新核对到保存的原始文件，论坛的可见文本与上文也按提取程序重算一致。

## 重合与划分风险

CSM 的 2,181 条与 RedTrans 中文原文的 1,428 条合并后，精确唯一原文为 **2,539 条**；其中 **1,070 条交集全部来自 CSM fun posts**。CSM snippets 与 RedTrans 无精确重合。两份本地 README 没有找到明确互相复用声明，不能据此推断来源先后或授权关系。

本轮所选 CSM 40 条与 RedTrans 40 条有 18 条重合，其余来源之间没有精确重合。RedTrans 所选 40 条中，29 条已存在于 CSM 全集。NFC 加去首尾空白另计的全集交集为 1,140 条，仅作附加诊断，不修改原文。WildChat 还存在措辞略异的同类请求；精确去重不等于排除了近重复。

后续不能按数据集名称直接分训练与测试。应按相同／近重复文本、对话、帖子及来源家族分组，再检查重合。CSM 的 snippets 可以与重合较多的 fun posts 分开看待。

## 对下一步的实际意义

1. 社交来源优先保留 CSM 的短评论和 CSM／RedTrans 去重后的帖子；大量汉字网语的价值是防止过度改写。别把中文含梗文本数量当成需要汉字释义的训练对数。
2. RedTrans 的容量、金额、比例及范围混写可补充常规 TN，但其数据及据此训练模型的非商业限制需保留。不要仅凭这次样本较丰富就确定为默认训练来源。
3. WildChat 可补真实用户提问与指令，本批没有支持把它当成高密度社交梗来源。论坛适合补上下文和技术标识保留对照，暂不扩大为大众网语主来源。
4. 这次没有验证保留对照上的模型错误，也没有证明引入上文会改善输出。下一步应先确定可接受输出，再以仅包含 `id/text` 的独立输入运行现有基线；模型输入不得混入筛查理由或未来参考答案。
