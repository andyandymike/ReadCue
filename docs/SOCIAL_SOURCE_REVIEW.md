# 中文网络表达来源复查

更新：2026-09-29。用途是 ReadCue ZH2 的来源筛选，不代表已确定训练数据、完成许可审查或测出模型收益。原文、译文、释义与朗读目标分别处理；本轮没有训练或付费调用。

后续已完成四来源的小样本采集与逐条筛查：143 条来源记录，精确去重后 125 条。发现 CSM 与 RedTrans 全集有 1,070 条精确重合。下表保留最初调研阶段的获取状态，当前实际结果以[小样本比较报告](SOCIAL_SOURCE_PILOT.md)为准；WildChat 已通过官方分页接口取得本批中文消息。

### WildChat 的规模边界

官方 `allenai/WildChat-4.8M` 卡片报告公共版有 3,199,860 段对话，覆盖至 2025-07-31。这是多语言总量，不能称为中文数量。早期论文的中文轮次比例不能直接套用到当前版本。本轮读取到 revision `c827c6df8fcf008219ffaffa4d1dd77491099367`、`gated=false`，仅证实元数据访问成功，中文筛选预览超时。

若后续取样，应只把中文用户消息作为待规范化目标，保留必要上文但不将 AI 回复当成人类原文或标准读法；不需要关联用户的 IP 哈希、位置或浏览器信息。先区分口语交流、代码、引用材料和长指令，再判断是否值得进入 ReadCue。

来源：[官方卡片](https://huggingface.co/datasets/allenai/WildChat-4.8M)、[采集与同意流程](https://arxiv.org/html/2405.01470v1#S2)、[ODC-BY 内容权利边界](https://huggingface.co/datasets/allenai/WildChat/blob/main/LICENSE.md)。

## 未提升为主来源的候选

- **NUS SMS 中文**：作者发布的 2015-03-09 版有 31,465 条；只接受贡献者本人发出的既有短信，贡献同意过程清楚。实际 ZIP 的 HEAD 为 HTTP 200、1,209,377 字节，未下载正文。但日期、时间、小数、多位整数和字母数字编号会被替换成占位符，破坏数字梗和型号，且缺少完整双向语境。论文使用 public-domain/open-license 表述，仓库未给独立精确许可文件；作为非数字历史口语补充，不能直接作 TN 主集。[作者仓库](https://github.com/kite1988/nus-sms-corpus)、[论文 §3.4、§4.4](https://arxiv.org/html/1112.2468)。
- **NaturalConv**：围绕新闻组织真人聊天，不是既有网络聊天记录。许可含个人非商业研究、不可转授权及派生作品分发限制，未确认可公开分发训练后的权重；不作默认训练来源。[官方条款](https://ailab.tencent.com/ailab/nlp/dialogue/papers/NaturalConv_Release_license.pdf)。
- **Bangumi**：资料条目的 CC 许可不覆盖我们更需要的原创日志、吐槽；后者需作者许可。[官方版权说明](https://bgm.tv/about/copyright)。
- **Chinese Stack Exchange**：内容 CC 许可与自动获取政策是两回事；现行可接受使用政策限制用于机器学习测试及评测等的自动获取。[官方政策](https://chinese.stackexchange.com/legal/acceptable-use-policy)。
- **DanmakuTPPBench**：有真实 B 站弹幕事件，但 QA 含模型构造。官方 HF 有登录及信息共享门槛，公开卡未核明数据许可；本轮未申请访问。[官方项目](https://github.com/FRENKIE-CHIANG/DanmakuTPPBench)。

## 对现有候选的影响

上一轮实际取得的 CSM-MTBench 中文原文仍比 MDN 更贴近社交表达。此次新增来源有不同的用途：WildChat 补多轮用户表达，RedTrans 补社交语境，论坛补原帖与回复可追溯性。它们都不是现成的中文朗读输入—输出配对。先抽样比较有效难例比例，再决定是否扩大获取；尚未改变项目范围、冻结评测集或训练计划。

## B 站评论与弹幕：后续重点来源（2026-09-29）

后续获取实测已完成：公开HF评论库可分页读取，实际取得300条；另已下载全部9个评论对话示例和bilibot的1,916行格式化材料。详见[实际数量、字段与获取记录](BILIBILI_ACCESS_PROBE.md)。以下保留此前候选研究过程，不能将所有候选都视作已经取得。

用户提出 B 站的网络语可能更集中。后续来源调查优先考察 B 站评论与弹幕；这属于语言分布适配判断，尚无跨平台同口径统计支持“网络语最多”的排名。前一批125条独立文本的筛查结果不能外推为 B 站难例率，也不能据此否定网语朗读的价值。本次仅核验论文、发布入口与条款，没有抓取新的站内评论或弹幕，没有训练或申请访问权限。

### 论文提供的证据

- [CCL 2021 的弹幕语言研究](https://aclanthology.org/2021.ccl-1.93.pdf)第4–5页介绍 B 站语料，表1直接列出谐音、重复语气与数字表达。它支持弹幕确实含目标语言现象，不能证明新模型相对现有 TN 有收益；该论文中的数据量不是本项目已获取数量。
- [CSCW 2021 评论／弹幕比较](https://hechangyang.com/papers/CSCW21_danmaku.pdf) §3.2.2、§3.3 描述重复字母、颜文字、方向箭头及视频指代。研究针对疫情视频，不能把结论不加区分推广到所有分区。作者为分类压缩重复字符、将表情和箭头改为语义文字；这种处理不能直接作为 ReadCue 的原文或朗读标签。

对本项目的推论：评论及楼中楼优先用于完整句子、回复关系和口语保留；弹幕单独用于短表达、重复、符号和缩写边界。保留视频来源与时间位置作离线审查依据，但不因语义理解需要画面就自动扩大为多模态模型。读法确实无法从文本确定的案例应单列，不借视频信息制作标签后仍声称纯文本一定能预测。

### 获取与发布边界

[B 站用户协议](https://www.bilibili.com/blackboard/protocal/licence.html)官方 URL 的可检索新版索引中，§5.6(3)规定自动程序、脚本获取内容或数据需事先明确书面许可；§4.4的评论／弹幕二创许可有限定平台与非商业条件。不能从页面公开或接口可响应推导出训练和公开 HF 权重的完整授权。[开放平台开发者协议](https://openhome.bilibili.com/agreement/developer-service)也限制授权范围和使用目的；UP主管理评论不等于其可代表所有评论作者授权训练。

核验限制：本轮官方动态协议页的直接正文提取为空，具体条款来自搜索工具对官方 URL 的索引正文；没有将旧版活动页当成新版协议。以上不等于判断所有 B 站相关研究或训练都被禁止，而是尚未确认我们所需的具体获取、训练及权重发布授权。

下一批取样设计应覆盖游戏、动画、生活娱乐、知识技术等不同内容，兼顾热门与普通讨论；评论和弹幕分别计数，保留重复字符、数字串、大小写和表情，不预先纠错或解梗。先用来源与权限明确的原始材料检验这些现象，再决定是否新增自然朗读策略；现有冻结协议与72条基线不作追溯改动。
