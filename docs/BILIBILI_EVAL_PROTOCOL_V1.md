## 材料与输入隔离

使用 `reviewed-01-2026-10-01` 固定导出的 138 条批准样本、141 个可接受完整读法，另两条纯表情已排除。此批经过助手预标注和用户审核，是已查看的探索材料，不是盲测或独立随机抽样，没有训练／测试划分。原文自述含生成内容的一条单列分析；不能称全批均为真人原创。
