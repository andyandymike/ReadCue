## 处理与来源

按相同顺序处理所有输入：冻结的v1署名／表情规则 → 有来源的有限英文读法词表与产品版本规则 → 原固定专用TN → 编辑保护检查。原v1实现、数据、参考、结果均不改动。

词表由独立任务从公开一手术语／产品资料整理，不读取原138条或挑战集参考、预测、标注来提取映射。上轮暴露的类别缺口用于选择本轮任务，因此不能称开发方向未知。官方拼写、官方名称、明确发音证据与项目读法约定分别记录；来源只支持名称时，不将逐字母策略冒充官方发音。用户明确约定up按英语单词、YYDS及JDK逐字母、tomcat按单词，另标记为用户策略。

仅匹配完整token。已知单词保留原拼写及大小写；initialism写成空格分隔的大写字母；compound按固定词段与字母段组合。未知项及多读法项保留并警示，不把所有大写词自动拆字母，不音译或补释义。引用、代码、网址、普通方括号和正文提及继续受保护。输入中写着“请原样保留”是待处理文字，不被当作动态控制指令；因此先前合成例子的个别参考可能与本轮新增规则冲突，应如实计分和解释，不改参考。

仅对词表已登记的产品词干处理紧邻的版本号。可以解析全由已知词干与版本组成的粘连串；若存在未知尾巴则整串保留。版本点是分隔符，每个整数成分转中文数量，前导零成分逐位，不能用浮点数吞掉零；非前导零成分超过16位时整串保留并提示。这是明确的项目约定，不声称唯一读法。未知字母数字标识额外受TN保护，避免在其中擅自展开数字；若TN触碰它，整条回退并以非成功状态计分。

保留v1的TN保护边界：顺序锚点、锚点含数字、原汉字顺序保留、禁止触及受保护区。不能保证新增文字、数值或所有语义正确。纯数字编号、多义网络词、装饰符号覆盖、网址省略和生成声明省略不作为这轮临时补丁。

## 语音小样

使用本机已经安装的Microsoft Huihui Desktop中文SAPI voice，rate=0、volume=100、16-bit mono PCM WAV。不安装系统语音、不改注册表、不调用云语音、不下载新权重。输入强制为纯文本而非XML。记录voice标识、参数、输入与音频哈希、格式、时长和失败状态。

准备少量原创短句：既包含用户关心的词／版本，也包含独立技术术语。每句保留原文与由冻结处理链产生的规范文本，各合成一份。不得拿人工参考替换模型输出伪装成处理链效果；若输出被保护拒绝，应标注回退，不能作为成功读法展示。

音频生成、结构检查、自动文本分数、人类试听是不同证据。本轮提供可播放的小样和核对点，未听到实际音频时只报告生成成功，人类发音接受状态保持待核对。旧协议的“未评估音频”仍描述旧实验；本轮仅增加有界试听接口，不声称已证明TTS收益。
