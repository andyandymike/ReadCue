# 首轮模型的标注政策 v1

日期：2026-10-01。对应 `configs/model_task_v1.json`，在新评测编写及训练前固定。只用于本次新版本材料，不回写旧参考和成绩。目标为整句输入、整句朗读规范文本输出，不包含音素或音频；输出写法符合政策也不直接证明 TTS 发音正确。

## 转换与保留

- 明确数量、金额、百分数、日期、时间及单位按句内意义展开；编号逐位读，普通数量按数值读。年份逐位，月份及日期按数值。小数点后逐位读。数值与单位意义必须保留。
- 明确英文缩写以空格分隔的大写字母标示逐字母读法，例如 JDK 写为 `J D K`、YYDS 写为 `Y Y D S`；up、tomcat 等普通英文词保留词本体。词后紧接版本号时仅按明确的版本读法展开数字。不从大写形式单独推断所有词都是缩写。未知品牌、型号或词义不确定的组合保留，另记待核对。
- 本轮沿用已有明确政策：u1s1 为“有一说一”，学校工程编号 985 为“九八五”、211 为“二幺幺”；只有局部语境明确支持时采用。金额、件数、书本数量等不按学校编号读。YYDS 保持字母读法，不改成词义展开。
- 明确的句首 `回复 @昵称：` 是回复界面署名，连同署名分隔符省略；正文中的 @、邮箱、代码及被引用的回复格式保留。其他孤立昵称不自行删除。
- 附加的情绪表情和平台表情标记省略。图形明确作为正文中的字面名词时可写出相应词；隐喻、讽刺、含混的词义不猜测。只有表情而无可读正文的样本单列，不生成空目标凑训练数。
- 代码、URL、文件路径、正则表达式和明确要求逐字引用的内容保留。引号本身不自动等于代码；依据句内用途判断。
- 保留事实、否定、程度、实体、语气、数量含义及目标以外正文。保留原标点和已有空白，除转换内部必需空格、被省略署名所含分隔符外不额外排版。
- 多种明确合法读法可保存为 acceptable_outputs，训练采用明确登记的一个 target。不用模型输出反过来挑选参考。无法给出确定目标的条目留在 pending 清单，不加入监督目标。

## 记录与角色

每条训练/验证材料记录原始版本、原始文件/文本/参考哈希、来源与用途、新目标、修改理由、政策版本、审核者角色及模板组。旧材料全部已见；其新用途是训练/验证，不再称独立测试。助手按政策复核属于助手标注，不冒充用户逐条批准。

新增评测由不参与训练数据和实现的独立标注任务编写，在训练前冻结。训练与验证入口不读取评测参考；选点后才由离线评分读取。材料是项目原创合成句，不能宣传为真实评论分布或随机盲测。疑似近重复由独立核对记录，模板及仅数字/实体替换的变体不得跨角色。

本轮优先使用原创材料并为新派生版本明确登记项目研究训练用途；原始评论继续保留为开发诊断。输入不携带参考、类别、预期跨度或审核备注。该说明及任务提示的哈希写入数据和运行清单；开始运行后修改政策须另开版本。
