# 评论语境读法 v3：小修复与新真实评论验证

日期：2026-10-01。用户授权修复网络缩写和学校编号、核对原本正确的读法，并用20～30条新真实评论验证。本轮取24条。免费本地运行，不训练、不调用付费服务；没有ReadCue权重。

## 方法与冻结

处理顺序为冻结的评论清理、冻结的27项英文词表／版本规则、新增有界语境层、原固定专用TN、编辑保护。旧文件不覆盖；新层和新入口另建文件，在首次模型运行前记录源码、资源、输入和参考哈希。模型revision及参数沿用v2。保存纯规则、TN原始输出、保护后输出和失败状态。

新增规则依据用户授权的读法政策和独立公开来源，不从评测参考提取词典。公开资料中的词义／工程名称证据与项目选定的中文读法分别记录。只处理独立token；代码、引用、网址、账号和完整标识不作为普通网络用语。学校编号需要明确教育语境；紧邻计量单位、金额或其他明显数量用途优先保留数量解释。含糊情境不强猜。已确定的展开结果受到TN保护，避免后续再次改坏；拒绝仍记录为非成功状态，不能因回退等于参考就算通过。

## 数据角色与隔离

原138条已审评论、以前的两组各24条合成检查及4个试听短句均已查看，只作开发和回归。增加一组明确标为项目原创的定向控制，覆盖普通数量、学校数量、品牌、字面边界和已知正确读法。它们用于工程回归，不能充当新的真实评论。

新24条来自有来源记录的公开原始评论，保留原文、不拼接或改写；与旧140条审阅材料排除相同ID、精确文本和近重复。优先复用已获取但未入前轮评测的原始材料；因此“新”表示新评价案例，并不表示2026年新发表或跨来源独立。如果与开发材料同视频或同档案，明确报告。选择不依赖新模型输出，保存固定抽样方法和未满足的类别覆盖。

新参考由单独任务在推理前提出并固定，未经用户审核，不能冒充用户gold；含糊条目标记待核对。输入文件仅有id/text；执行新旧推理的任务及程序在两组推理都完成前不读取新参考内容。不把本轮描述为无污染盲测，挑选任务曾接触旧材料的事实明确记录。新结果揭示的问题不得通过原位改标签或资源后重跑覆盖首轮结果。

推理前已知新批次包含22条助手建议参考和2条待审。全部24条进入推理、状态核对与音频生成；文本匹配仅对有参考的22条另列，并始终同时报告总批次24与待审2。待审不默认为正确或错误，也不修改冻结scorer来接受空参考。任何有参考案例的执行失败仍计入该评分组分母。

## 对照与核对

新v3运行全部输入；v2对已有材料复用冻结结果，对新24条及新增控制运行旧实现。核对严格匹配、冻结格式归一匹配、新增成功／退步、原文保留组、警告和保护拒绝。所有失败保留在分母。新真实材料的助手参考分数与旧人审开发分数分别列出；不把任何文本分数当作发音准确率。

新24条均生成原文和v3实际输出的音频；少量已知失败和原本正确的控制也生成对应音频。文本必须来自实际预测，人工参考不能冒充修复结果。对于失败后回退的输出明确注明，不按成功样例展示。使用原固定本机Huihui SAPI COM声音与参数，不安装或下载语音模型。

可使用解码PCM精确比较和同声音的发音事件辅助筛查，但不同波形不等于不同读法，更不等于改进。先前System.Speech接口的英文事件不完整，不能凭缺事件认定英文漏读；其事件仅绑定自身生成的音频，不能自动转移到COM音频。人耳验收仍由用户提供，不自动标记“已通过”。

## 保存与结论边界

原始评论、来源、未经人审的参考、逐例结果、音频和日志在仓库外E盘；Git仅保留原创实现、合成测试、协议和聚合结论。保存原先归档核验、首次运行前冻结时间和完成后读取参考的时间。新真实材料仍受原来源条款约束，本轮研究使用不解决未来训练或权重发布许可。

本轮交付为实际修复、回归结果和供核对的少量关键音频；发现新的真实错误不自动构成自训理由。只有跨新材料反复出现、现成方案仍无法可靠解决的需求，才进入训练路线和预算讨论。
