# 更新的 B 站语料：获取与日期核验

核验日期：2026-09-29。问题是能否取得晚于已有“2023 年热门视频评论库”的材料。本轮只调查公开发布的数据并做有界下载、字段和时间统计；没有直接爬 B 站、登录申请、联系作者、付费或模型训练。

## 当前结论

可以取得更新的材料，已实际获得带 2024–2025 年评论时间的公开 CSV。优先继续审查保留视频、评论与回复关系的原始评论；原神社区评论可补充游戏网语方向，其他弹幕线索仍需核清来源。这里报告的是文件审计，不是 ReadCue 模型结果，也未逐条回到 B 站验证原帖。

严格区分评论发帖时间、视频发布时间、数据采集时间和数据集发布／更新日期。2026 年发布的论文或数据卡本身不能证明包含 2026 年原评论。本轮尚未确认可直接取得、日期可核的 2026 年原始 B 站评论集。

## 已实测的来源

### IT 与 AI 讨论评论：可直接取得 2025 年材料

来源：[yunyunfanfan/job_change_as_ai](https://github.com/yunyunfanfan/job_change_as_ai/tree/752b8ee5a2cb4ddc20de7b68a4f3994a1ca40f63)。固定版本 `752b8ee5a2cb4ddc20de7b68a4f3994a1ca40f63`。

- 已下载 `data/data_bilibili/` 下 7 份原始 CSV，共 **2,335 条、7 个视频**；评论 ID 全部唯一，精确唯一文本 2,280 种。
- 按原始 `ctime` 转为 UTC+8 统计：2023 年 631 条、2024 年 281 条、2025 年 1,423 条；晚于 2023 年共 **1,704 条**。
- 时间范围为 **2023-03-29 13:46:59 至 2025-12-01 23:37:22（UTC+8）**。这是文件字段的实测，未独立核对站内原帖。
- 保留 `bv_id/oid/rpid/root_rpid/parent_rpid/ctime/message`。1,439 条有非零父评论，指针全部可解析。后续pipeline核对采集源码发现：作者把二级回复的parent统一写成root，因此只能恢复根评论上下文，不能认定保留真实直接回复对象。见[来源语义修正与首批整理](../reports/bilibili-data-v1/REPORT.md)。
- README 的“1,215 条、1 个主贴”与当前原始文件不一致；处理后的合并表也只有 2,328 条 B 站记录，不能替代原始 2,335 条。后续原文审查以原始 CSV 为起点，保留两版本差异。
- 主题集中在 IT、AI 与职业讨论，不能代表 B 站全站网语。未发现独立标准数据许可证，README 声明学术研究并要求遵守平台条款；不据此承诺训练权重可宽松发布。

### 原神社区评论：游戏方向的较新补充

来源：[Genshin Impact Community Insights: Videos & Comments](https://www.kaggle.com/datasets/kelvinkeekwongyew/genshin-impact-bilibili-videodataset)，核验版本 v3。

已匿名取得评论 CSV 的原始前 200,000 字节，从中无文本归一化提取 300 条完整记录，另取得完整帖子表 1,607 条。发布者声明采集窗口为 2024-06 至 2025-11；帖子表日期范围为 2024-06-28 至 2025-11-22。评论字段为 `Post_ID/Comment_Content/Cluster`，评论没有自己的发帖时间。前 300 条样本均关联到同一个、上游标为 **2025-11-21** 发布的视频；因此可推断相应评论不早于该视频，但这个推断依赖上游 `Post_ID` 关联和相对日期换算，不能称为逐条评论时间已独立核实。评论 CSV 全文件为 59,217,051 字节，未下载全量、未测总行数。

这是上游已聚类处理的发布版，不是未经变换的站内 API 原包；`Cluster` 不是朗读标签。发布者标注 CC BY-NC 4.0，具体原评论授权与未来权重条款仍需核清。适合继续检查游戏网语，不能将单游戏分布外推全站。

### 2024 年弹幕样本：日期明确，来源信息不足

来源：[wybxc/danmaku](https://huggingface.co/datasets/wybxc/danmaku)。HF 元数据版本 `f9b162afa2c71714602d55839ff62e84e48b888b`，报告全库 393,609 行。

本轮仅取首、中、尾三个固定窗口各 100 行，共 **300 条**，并非随机代表性样本或全库下载。样本 `time` 全在 **2024-11-02 至 2024-11-09**，字段含 `progress/time/id/hash/color/mode/size/text`。

数据卡缺少可核明的平台、源视频映射和独立许可说明，不能只凭弹幕字段就称它为已核实来源的 B 站语料，也不能称为直播聊天。可保留作补充线索，优先级低于有视频来源的评论 CSV。分页接口读取 current main，原 GET 未保存响应版本头；随后 HEAD 的 `x-revision` 与元数据一致，但不能据此把原 GET 改称固定版本请求。原始响应与哈希已保留。

### 另一份 2025 年评论材料：先隔离质量问题

[XMengHan/DataJournalism_Prj](https://github.com/XMengHan/DataJournalism_Prj/tree/4f1c769850716b0dda7bee19e2d3fb47eb619ca1) 固定版本 `4f1c769850716b0dda7bee19e2d3fb47eb619ca1` 的评论 CSV 可公开下载，但实测不支持直接照抄 README 的“约2,100条、2024–2025年”。

实际解析 12,414 条记录，其中 5 条列数破损；完整列记录中，4,005 行评论 ID、1,866 行视频 ID 已变为低精度科学计数法，无法可靠还原身份。合理时间字段子集为 12,398 行，覆盖 2018-06-11 至 2025-12-09，其中 2025 年 8,935 行，但含重复，不能当独立评论数。原始字节与异常记录位置均已保存，没有静默修复或删除。

README 的 MIT 声明含未填版权占位符，未发现根目录 LICENSE；内置 MediaCrawler 软件许可也不等于数据授权。仓库另有模拟数据回退代码，但原 CSV 的结构不同且未精确命中其模板，不能仅凭该代码断言 CSV 造假。此来源暂作隔离候选，优先使用上面字段完整的 7 视频评论材料。

## 对 ReadCue 的下一步

先从已取得的较新评论中检查数字串、中英混写、缩写、重复字符、表情与回复依赖；保留原文，不预先纠错、解梗或生成 gold。探索时保留视频及评论来源供离线审查；将来做对照时仍只送协议允许的输入，避免把参考或事后分类传入模型。

IT／职业讨论和单一游戏都有主题偏差。扩大材料时优先补动画、生活娱乐等不同视频来源，并按视频隔离开发与评估材料；不能把已看过的公开样本称为盲测。是否自训仍由 ZH2 的真实缺口决定，本轮不改变模型、训练或预算范围。

如果需要 2026 年持续更新的语料，下一条路线是面向近期视频的授权定向采集或取得作者已有导出。[B 站用户协议 §5.6(3)](https://www.bilibili.com/blackboard/protocal/licence.html)对自动程序获取内容要求事先书面许可；公开爬虫工具能运行不等于已取得所需获取和发布授权。官方动态页正文提取为空，此条款核对来自搜索工具对官方 URL 的索引正文。本轮未运行站内采集工具。
