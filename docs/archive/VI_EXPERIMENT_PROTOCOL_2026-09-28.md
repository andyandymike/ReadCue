# ReadCue 首轮实验协议

状态：立项设计，尚无模型实验结果。基于[论文深审](../../research/ugtphon-2026-09-28/paper-audit.md)和[数据审计](../../research/ugtphon-2026-09-28/data-audit.md)。实现时需给此协议版本号并记录变更。

## 统一输入输出

首版输入是句子、语言和一个给定目标跨度，目标允许跨多个空格词。跨度的具体存储方式在实现前固定，并验证能精确还原目标文本。禁止假定token数组长度等于按空格分词后的长度。

所有目标使用相同输入格式和输出结构，例如canonical与IPA两个字段。词典命中与否仅取决于输入surface和冻结的训练词典；不得根据测试gold is_nc切换提示、选择处理路径或输出格式。当前样本的gold canonical、phoneme及类别可作训练监督和评测标签，不能传入推理输入；仅从冻结的训练词典检索出的canonical hint可以作为输入。

应用按分词枚举目标不等于已解决自动目标选择；自动分词/选目标的误差和耗时须单独评估。

## 数据划分与规则来源

- 固定UGTPhon commit `da2b3ee84e15e98ba48b388f7ee291ba4c3579b2` 和源文件哈希。
- train：训练样本、提示词典、多数映射与平票规则、标准词保护表、候选过滤。
- dev：选择检查点、训练配置及有限预先记录的实现选择；不把dev标签加入训练词典。
- 官方test：固定公开benchmark，在模型实验中不按其分数调参。**立项审计已读取并分析该test**，包括重复、词典覆盖及异常映射；不能称其为从未查看的盲测。
- 独立新评测：用于外域/新词/真实接入效果主张；其来源、许可、隔离方式和采集方法需另行确定。

Unicode NFC和空白处理须在train/dev/test一致。逗号可能是标点、数字分隔或多候选标注，不得无条件拆分。清理前后要保留映射与数据版本；原始gold评分和有语言依据的IPA变体评分分开报告，不静默删掉发音标记。

## 三类对照

| 对照 | 内容 | 要回答的问题 |
| --- | --- | --- |
| B0 词典方案 | 训练多数词典、train标准词保护、固定G2P后端 | 简单方法已经能做到什么？ |
| B1 普通微调 | Qwen2.5-0.5B的普通任务微调 | 专门训练本身带来多少收益？ |
| B2 上下文与提示 | 相同基座、上下文输入、train-only提示 | 新设计能否进一步改善保真与非规范词？ |

已归档的B0结果只完成规范化EM，**没有完成固定G2P后端后的PER**。实现后才允许与模型音素成绩比较。

B1/B2固定相同基座revision、数据版本、训练预算、解码参数和评测目标集合；明确IPA-Dict前置训练或warm-start是否存在以及是否共享。输入上下文、提示和输出目标的差异逐项记录，不能把同时变化的所有收益归因于一个组件。先做有限运行，再依据结果决定是否增加随机种子或消融。

不先做LLM词典扩增，不需要付费教师数据来跑第一轮。

## 评分与记录

1. Canonical EM：目标规范形式完全匹配率，明确多候选与大小写规则。
2. IPA EM：音素字符串完全匹配率，与PER分开。
3. PER：实现前固定音素切分、音调/重音、空标签和多候选规则。论文未公开完整评分器，未对齐前标为ReadCue协议，不能声称精确复现论文数字。
4. 标准词保真：新增错误率的分子为原样保留本来正确、经系统处理变错的标准词数，分母固定为全部标准词token数，与归档19.26%/0.21%的口径一致；不能把所有改写均视为错误。若另以原样保留本来正确的子集为分母，须另名报告条件错误率。
5. 分层：标准/非标准、train已见/未见surface、类别、来源；is_nc等标签只用于离线分组。
6. 部署开销：固定设备记录目标数、输入/输出长度、延迟和内存。逐目标预测不能用一次推理时间代替整句成本。
7. 实验记录：随机种子、实际费用、失败运行、完整配置、检查点选择原因和结果文件。

如果作优劣主张，使用相同样本的配对比较并报告不确定性；不以不同系统各自置信区间是否重叠替代差异检验。不把EM换算成PER、不把PER当句子成功率、不把音素评分当人类听感。

## 研究发布与应用验收

可复现训练、可加载权重和完整模型卡足以构成研究发布；诚实的负面结果也可以发布。要宣传模型更有用，还需在同协议下相对B0/B1展示可解释的收益，并说明标准词保真是否退化。

接入TTS时另选固定语音后端，记录音素映射、未知符号、声调及标点处理，再进行真实输出评估。Kokoro、Piper或其他前端的接口可用不等于任意IPA兼容。未完成语音实验前，不宣传提升听感。
