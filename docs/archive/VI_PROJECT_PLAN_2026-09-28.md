# ReadCue 项目计划

立项日期：2026-09-28。

## 目标与定位

训练并发布一份别人可以独立下载、评估和继续研究的 Hugging Face 小模型权重。首版聚焦越南语非规范文本：结合上下文决定目标词应保持原样还是展开，再给出音素。

项目名为 **ReadCue**，首个候选模型为 **ReadCue-VI-0.5B**。以 Qwen2.5-0.5B 为候选基座，基于 UGTPhon 研究开展复现与有限改进；无需为了发布而另造架构。ByT5-small 作为后续有明确需要时的对照，不在首轮同时扩展所有语言和骨干。

预期使用者是网络文本规范化、越南语发音前处理和 G2P 研究的开发者。目前没有下载需求或生产效果的实测证据。

## 当前已完成与未完成

已完成论文与附录审查、官方资产检查、英语/越南语六份数据的固定版本校验、句子重复检查和训练词典对照。原始数据约38.3 MB，未复制进此仓库；已有聚合结果和复查脚本随项目归档。

尚未开始模型训练、GPU租赁、付费API调用、语音实验或HF发布。论文指标不属于ReadCue；数据/词典审计也不能证明候选模型已经有效。

## 首版范围

- 输入：越南语句子与一个明确给定的目标词/短语跨度。
- 输出：统一的canonical与IPA结构。正常词也使用同一结构。
- 提示词典：只来自训练集，缺失时使用统一规则。
- 推理：不读取人工给出的is_nc、canonical、类别或测试集答案。
- 交付：完整权重，或明确基座版本的adapter；tokenizer、配套词典、推理示例、模型卡和可复现评测。

自动分词、自动选择目标、整句一次输出、跨语言混合、音频生成与TTS听感提升属于后续独立能力，不继承目标词级评测成绩。

## 为什么值得先验证

2026-09-28的越南语审计中，简单训练词典在所有测试词上统一查表，非规范词的规范化完全匹配率为77.88%，但新增标准词错误率为19.26%。只用train过滤标准词冲突后，两个数分别为39.03%与0.21%。这是查表覆盖与保真的取舍；少数异常训练映射也会放大原始词典错误，不能据此直接证明神经模型必要。

首轮要检验模型能否改善这个取舍，并处理词典未见形式。上述数字是canonical EM及新增错误率，不是音素PER或听感成绩。完整证据见[数据审计](../../research/ugtphon-2026-09-28/data-audit.md)。

## 里程碑

| 阶段 | 产物 | 完成条件 |
| --- | --- | --- |
| M0 立项 | 本计划、协议、数据许可说明、审计归档 | 定位与证据边界明确 |
| M1 数据与评测 | 固定版本预处理、目标跨度校验、评分器、简单对照 | 不读取测试答案构建输入；重叠、IPA变体、异常标签有记录 |
| M2 小规模训练 | 普通微调与上下文提示两个候选 | 同基座/数据/预算下可复现；保留耗时与费用记录 |
| M3 效果判断 | 标准词、非规范词、已见/未见词分层结果 | 与简单对照比较，区分工程成功和实际效果 |
| M4 HF研究发布 | 权重、词典、模型卡、评测、推理示例 | 来源和发布条款明确；模型可独立加载；能力表述有实测支撑 |

M4可以诚实发布复现或负面结果。只有实际胜过相同协议的对照，才宣传应用改善；训练成功和产出权重并不等于效果验收通过。

## 预算参考

首轮规划约 **200–500美元**，用于有限训练、对照和调试。这是估算，**不是GPU租赁或付费调用授权**。

论文每次运行约24 V100 GPU小时，但是否覆盖IPA-Dict前置阶段未写清。2026-09-28查到的Google Cloud V100单价为2.48美元/GPU小时，折算约60美元/次，仅作量级参考；供应商、显存、训练配置与实际耗时尚未选择或测量。配套VM、失败重跑、人工检查及完整三语复现不包含在单次数字中。

先使用train-only提示词典，不安排付费扩增数据。训练启动前按实际设备和吞吐确定批次上限，并记录真实支出。若数据问题、同口径基线或验证结果否定模型价值，就保留研究结果并调整范围，而不是仅因已经训练就继续扩大投入。

## 主要待解决项

1. 论文的标准/非标准词推理处理描述存在歧义；ReadCue必须实现不依赖gold状态的统一协议。
2. 越南语音素转写存在差异，不能为提高分数静默修改标注；部分异常映射需要母语者复核。
3. 官方test已经用于立项前探索分析，是公开benchmark，不是全新盲测。外域能力需要新的独立评测。
4. 越南语数据限制非商业使用；辅助词表上游授权和权重发布条款还需核清。
5. 暂无现代TTS或人类听感收益、推理延迟和实际用户需求验证。
