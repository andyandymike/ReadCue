# ReadCue LoRA v1 本地模型卡

日期：2026-10-01。状态：已训练并独立加载验证的研究adapter，尚未公开发布。完整运行条件和测量见[实验记录](MODEL_EXPERIMENT_RUN_V1.md)。

## 用途与输入输出

研究中文句子中的读法选择：整句输入，返回适合朗读的完整文本，包括明确数字、缩写、回复署名和表情的处理，并保留其余正文。输入仅为原文；ID用于记录，不进入模型。采用[固定任务提示](../configs/model_task_v1.json)及[标注政策](MODEL_TASK_V1.md)。输出不含音素，也不生成音频。

该版本用于有限规模的离线研究。其数量、编号和实体改写存在错误，不能把生成文本视为已核准内容或直接宣布朗读改善。

## 组成与训练

- 基座：Qwen/Qwen3-0.6B，revision `c1899de289a04d12100db370d81485cdf75e47ca`。
- Adapter：LoRA，q_proj/v_proj，r8、alpha16、dropout0.05；1,146,880个可训练参数。
- 数据：118条训练、29条验证，均为项目助手原创情境的新版本；13条未定目标隔离。B站评论和专用TN输出没有进入监督目标。
- 训练：固定种子20260928；3个epoch、45次更新；按验证目标token交叉熵选中第三轮。验证材料来自已看内容，不宣称未见测试。
- 设备：本地RTX2060 6GB；训练557.68秒，CUDA峰值预留3,927,965,696字节。无外部API费用。

原文、旧参考、修改理由、用途、划分、配置、源码和权重哈希均单独保留。数据角色与近重复检查见实验记录。训练依赖见[实际环境锁文件](../requirements-model-v1.lock)，核心工具不强制安装模型依赖。

## 实测与局限

在训练前另行冻结的55条助手原创情境中，整句匹配为28/55；同提示未微调基座0/55，固定规则26/55，返回原文16/55。基座经常输出翻译或额外改写，比较结论仅适用于本次固定设置。模型在普通TN为7/19、语境读法7/20、原文保留14/16；固定规则的语境读法和原文保留分别为10/20、16/16。

模型能完成部分展开，但仍有明显错误：普通数量与编号读法混淆、缩写漏展开、数量值或实体被误改。两条保留案例被不必要地改写。18/44局部目标通过机械匹配；独立助手隐藏方法名审阅全部220个候选后，对本模型确认19/44个局部目标完成，同时标出7/55句语义错误，其中保留组1/16句。多出的1个局部完成是删掉表情却多加句号，原始整句分数不变。这些是助手文本判断，不是听音核验；定义与具体错误见实验记录。

训练量很小且类别覆盖不均，YYDS和部分字面表情家族未在训练中出现。评测是合成情境，不代表真实评论分布；助手参考和助手复核不等于用户批准。没有进行语音评估、多种子稳定性实验、最佳提示搜索或公开基准能力测量。尚不能据此宣布优于现有系统或可用于直接改写正文。
