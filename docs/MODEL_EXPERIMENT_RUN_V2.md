本批严格与表面匹配计数相同。v1的28/45是此次新45条上的重新推理结果，与历史旧55条的28/55是两份不同测量，不能混用分母。基座0/45仅描述这套固定提示与解码下的行为，不代表基座所有使用方式的能力。

v1→v2逐条配对：新增匹配4条（HEV2-002、015、020、026），退步0条，共同匹配28条、共同未匹配13条，净增8.9个百分点。普通TN新增3条，语境新增1条；这是单次有界实验的观察，不是统计稳定性或覆盖扩充的单因素因果证明。v2在同样3轮下更新63次，v1原训练为45次。

规则→v2：新增12条普通TN匹配，退步5条（HEV2-022、029、030、039、054），共同匹配20条、共同未匹配8条。规则不含通用数字展开，v2在语境组8/16仍低于规则12/16，保留组也少1条，不能称全面优于规则。

v2未匹配项包括缩写或网络缩略语未展开、时间读法不符合参考、单位表达、额外句号，以及含混狐狸表情被删除。整句未匹配不自动等于语义错误：例如公斤／千克、时间读法省略“分”的接受范围需单列审阅，原参考与首次分数保持不变。局部完成和保护跨度是机械对齐结果，也需与语义判断区分。

“确定新增语义错误”要求实际值、事实、实体、否定、关系或正文意义受损；单纯未展开数字、字母间距或格式差异另列政策违规。错误类别可以重叠，不能加总为句数。基座另有1条在已经确定存在其他错误的同时包含局部不确定判断，未额外计为一条语义未决句。局部完成也不代表整句合规：例如基座将字面龟图形转换成英语turtle，被记为局部名词意义转换，其余中文保留契约仍失败。

v1的两条确定数量错误为HEV2-015（109元→十九元）与HEV2-020（211元→二十一元）；v2均已修复。但HEV2-054中v2删除正文内的狐狸图形，令引句中与猎人谈判的另一方消失，审阅认定为实体／意义丢失。v1在同一条把图形写成“狐狸”，确定违反含混符号保留政策，但暗指是否改变仍未决。因此整句EM没有匹配退步，不代表所有错误类型都改善。

v1与v2对HEV2-010均输出“-八度”，负号未按读法展开属确定政策问题；“度”在气温语境中是否充分保留摄氏标度仍未决，不强计为确定语义错误。两者另一个共同问题是HEV2-039去掉附加表情后加句号：局部删除完成，但仍不符合原标点保留要求。

审阅对HEV2-009的“公斤”与参考“千克”、HEV2-012省略“分”的自然时间读法给出局部完整判断，并登记参考覆盖问题；连同HEV2-039，共使v1／v2的局部审阅计数分别较机械匹配多3项。未扩充acceptable_outputs、未回补整句分数，也未以审阅结果调整模型。
