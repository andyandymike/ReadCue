# 评论规则与专用 TN 组合：冻结协议 v1

日期：2026-10-01。用户授权实施上一轮建议的最小组合。本协议与代码、资源在本轮推理前固定；不覆盖已有72条pilot或138条四组实验。

## 目标与数据角色

先处理明确的句首回复署名和常见装饰表情，再由固定专用TN处理数字。保留没有把握的文字、符号和名称，不让通用模型重写全文。本轮不加入英文缩写读音、数字品牌、学校编号、网络词的答案词典，不定制单条生成声明删除规则，也不添加网址省略。

原138条经过人工审核的评论已查看、且其上一轮错误帮助确定此次方向，因此是开发／回归材料。它们的分数变化只能表明这批数据上的改善，不能称未见测试或泛化收益。原文、参考、划分状态和旧结果不变。

另由未获父对话、未读138条、实现或预测的独立助手，依据任务说明编写24条原创挑战样例，固定在 `comment-policy-challenge-2026-10-01`。这组覆盖署名、情绪表情、带词义符号、代码／网址／引用、数量和否定保真。它是作者独立的合成检查，未经用户审核，不是真实用户样本或正式盲测。实现者只收到输入，参考仅在推理结束后评分；看完结果不改参考或回头调规则覆盖原成绩。

138条与24条的 id/text 按固定顺序合并为162条组合输入，所有条目使用同一处理链，不按类别、参考或数据集分流。24条另跑未加规则的TN作对照；138条已有的原始TN结果及其冻结记录直接复用。纯规则输出也完整保存，以分清预处理与模型各自的作用。

## 资源来源独立于答案

- 平台token来自B站公开基本表情包1的实际响应：`https://api.bilibili.com/x/emote/package?business=reply&ids=1`。只取其明确的方括号表情名，本次取得225个；没有登录、下载图片或从评测文本／参考收集词表。无登录用户面板曾返回空列表，不使用它作为资源。
- Unicode来自固定16.0版 `https://www.unicode.org/Public/emoji/16.0/emoji-test.txt`。仅选face-*、cat-face、monkey-face、person-gesture、hand-*、hands子组的完整序列及列明的显示变体，共718个。词义物件、旗帜、数字、运算符、心形和普通装饰符号不在自动删除名单。
- 原始响应、获取时间、文件哈希和派生名单都留在仓库外。可复现的提取脚本是 `tools/prepare_comment_policy_resources.py`；重新联网取得的内容若不同，必须视为新资源版本。推理阶段只读冻结名单，没有联网。

Unicode分组是字符资料，不是“这个符号在所有句子中都无意义”的保证；依赖量词等上下文的保守保护仍会漏掉某些词义用途。资源有限，不识别的自定义表情会保留，不能把覆盖范围表述为全部B站表情。

## 处理链与可追踪编辑

1. 在原文码点位置生成可检查的编辑列表。仅识别第一行行首明确 `回复 @昵称 :` 或全角冒号结构，省略该前缀和紧邻的分隔空格，不删除正文内账号提及。
2. 反引号代码、网址、引号内文字以及未被确认的平台表情之外的方括号内容受保护。名单外的符号保留；名单内的情绪表情在量词或“是／像／当／成为／变成”等判断、比喻词之后保留并提示需核对。按完整序列匹配，避免删掉半个组合emoji。删除表情使两个ASCII词片段相邻时留一个空格，避免粘连。
3. 保存规则输出，再将非空 id/text 送入上一轮未改动的TN执行组件。模型、revision、FP16、greedy、1024-token上限及预热沿用上一轮；公共Qwen提示不适用于TN，也不参与此计算。
4. 对TN编辑脚本按原出现顺序定位。编辑不得触及代码／网址／引用等受保护范围，锚点须含数字，锚点已有汉字必须按顺序保留在替换文本中。违反即整条拒绝，保留清理后文本作查阅回退，状态记 `tn_guard_rejected`，不算模型成功。这是有限的内容保护，不能证明数值或新增文字一定正确。
5. 每条记录规则编辑、warnings、原始TN输出、TN预测、拒绝原因及最终状态。模型失败／截断不被回退掩盖；预处理后空正文也保留记录、计作非空任务未完成，不从分母静默移除。

父运行标识 `comment-policy-tn-v1`；子TN组件仍记录其历史执行配置标识。新规则、wrapper及来源提取器单独保存哈希；旧执行组件不被修改。模型只收到清理后的文本，既不读取gold也不加载人审建议。

## 分析与停止条件

继续使用原冻结scorer，分别报告严格匹配、表面格式归一匹配、保留组变化、规则覆盖、TN编辑拒绝与实际异常。分开列开发138条和挑战24条，保留原TN、纯规则与组合输出。所有分数仍是文本目标匹配，不能当发音或实际听感。

重点核查新出现的正文删除、否定变化、代码／网址改写，以及表情的词义歧义。不得因观察输出后新增词典或逐条补丁而覆盖本轮结果；需要改进时另建版本。本次无训练、付费API、GPU租用或TTS音频，所有第三方原文与逐例运行产物留在仓库外。
