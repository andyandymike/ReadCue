## 边界与实现

本轮新增独立comment v2、学校context v3、有限semantic emoji模块及新组合入口，旧源码、资源、参考和实验目录不改。学校修订只识别紧邻编号的学历/在读身份，保持数量、计算、字面标识优先级；不把任意附近教育词当无条件放行理由。

表情先区分正文词义和附加情绪。名词槽位与未解析物体不能直接删除；明确附加的情绪表情继续沿用省略策略。只有八个预先声明的物体符号在明确量词、谓词或比较结构中可转换为中文名称，其余保留并记录待审。不在本轮推断全部网络隐喻、把所有emoji都朗读或扩展到新模型架构。

八个物体符号为💩、🔨、🍎、🍋、🐕、🐈、🌹、🧱；名称取自Unicode CLDR 47中文tts annotation，commit `2ef784e3a4168bc2a43cd1b5b9839b6636f5899c`。构建器只读固定XML，不读评价材料，来源与Unicode-3.0许可正文留仓库外。标准名称是一种有来源的字面读法，不保证符合每个评论的口语或隐喻偏好；已有待讨论参考仍保持待讨论。

处理顺序为comment→semantic→reading→context→原TN。每个阶段保存编辑坐标并校验可重放性；保护区域随前序插入、删除和替换重新定位，生成的中文读法及未解析语义表情禁止TN再删改。保护拒绝仍算运行失败，不能把回退内容当成模型成功。
