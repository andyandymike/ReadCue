# v2 数据覆盖、首批样例与划分方案

日期：2026-10-27。阶段：数据准备；本页不记录新的模型效果。用户同意推进的首个交付是覆盖矩阵、首批原创样例和划分方案。

后续执行已将本页候选消费为显式v2数据包（166训练／53验证），保留目标与原角色；实际GPU运行被本会话的WSL访问拒绝阻塞。后续材料、评测冻结和验证状态见[运行准备记录](MODEL_EXPERIMENT_RUN_V2.md)，本页的首批候选记录继续按原状态保留。

## 要检验的问题

在同一 Qwen3-0.6B 基座、LoRA 结构和读法政策下，增加缺失技能及转换／保留边界的监督，是否改善新情境上的读法完成，同时减少数量、实体和正文误改？

沿用 [v1 标注政策](MODEL_TASK_V1.md)及原任务提示，不因新样例改变旧答案。首轮实测仍为55条合成情境中模型28条整句匹配、固定规则26条；助手语义复核指出模型7条语义错误。这些测量属于v1，见[原运行记录](MODEL_EXPERIMENT_RUN_V1.md)。

首轮数据审计发现，按原 `family` 字段统计，percentage、measurement、initialism_yyds 在训练中分别为0条，验证中分别为4、4、1条。训练中的YYDS照抄案例不等于字母展开监督。这是数据覆盖的直接证据；它尚不能证明补数据一定有效，也不能排除优化配置和模型能力的影响。

## 首批覆盖矩阵

首批计划为12项技能、每项3个不同模板组、每组2条，共72条。初始角色建议每项4条训练候选、2条验证候选；分组审计优先于此配额。样例由助手原创，保留作者身份与目标理由，未经用户逐条确认。

| skill_id | 学习内容 | 必须覆盖的边界 | 初始训练／验证 |
| --- | --- | --- | --- |
| quantity_identifier | 数量与编号 | 按数值读与逐位读；不由远处关键词推断 | 4／2 |
| decimal_reading | 小数读法 | 小数点后逐位；明确引用的小数字符串保留 | 4／2 |
| percentage_reading | 百分数 | 百分数值不变；代码／字面串中的百分号保留 | 4／2 |
| measurement_reading | 度量表达 | 数值与单位意义不变；受保护字段保留 | 4／2 |
| date_time_reading | 日期与时间 | 年份与月日读法；日期格式字面引用保留 | 4／2 |
| quantity_negation | 数量与否定限定 | 不改数值、不丢“不／仅／至少”等限定 | 4／2 |
| initialism_reading | 明确缩写 | YYDS、JDK等展开正例与引用保留 | 4／2 |
| english_word_boundary | 普通英文与缩写 | 单词保留，明确字母缩写展开 | 4／2 |
| unknown_identifier | 未知实体／型号 | 不猜型号读法；只改句中确定的其他内容 | 4／2 |
| reply_signature | 回复署名 | 句首界面署名省略，正文提及／引用保留 | 4／2 |
| emoji_context | 表情语境 | 附加情绪、明确字面名词、受保护引用 | 4／2 |
| protected_literal | 代码、链接、路径 | 保护范围内保留，范围外明确数量可转换 | 4／2 |

这些是定向开发技能，不是自然文本类别频率。技能编号与 `track` 不等同；每项均单列转换／保留数量。数量与编号的对照可均为转换，保留控制由其他技能补足。不为达到数量目标接纳歧义标签。

首批文件及逐条说明见[样例包](../eval/zh_reading_model_v2_seed/README.md)。它们是可公开复查的项目原创开发样例，与原pilot一样单独声明原创材料许可；不包含第三方原始评论、权重、预测或付费输出。

## 划分与跨版本隔离

1. 原118条训练、29条验证保持旧角色。原13条待审仍隔离；不能因需要补数量自动纳入。
2. 新样例先按模板／近义表达及对照关系组成整组。同一数字或实体替换模板的变体不能跨角色。保留 `proposed_role`，通过联合审计后再另存最终角色。
3. 对v1及新增文本联合检查原文、NFKC／大小写／空白归一、数字模板和近似句式；声明模板组、人工语义检查补充自动检查。自动相似度只是筛查，不能证明没有实体替换或语义近重复。
4. 新组连接旧训练组件时只能进入训练，连接旧验证组件时只能进入验证；若同时桥接两边则隔离整个新组。不能靠换ID、换组名或静默移动旧样例消除冲突。组内有一例冲突，先处理整个组。
5. 旧55条只作回归及防重用检查。审计读取其 `id/text`，不消费答案或预测生成新目标；新增材料不能是其答案回填或仅换数字、实体的改写。排除记录须保留原草稿，不能用改写来绕过已命中的旧评测模板。
6. 每项技能至少保留两个不同的训练模板组、一个验证模板组，并检查转换正例覆盖。不能再次将整项技能只放验证。某组隔离后若覆盖不足，新增独立情境或调整全组用途，保存版本理由。

推荐正式v2使用“v1训练＋合格的新训练”和“v1验证＋合格的新验证”。若72条初始48／24划分全部通过，合计166／53，仍在既有256／64数据上限内；这是条件性预计，不能冒充已冻结的训练包。合并后的 `track` 分布和技能覆盖应随正式包记录，不只报告新增部分。

## 新评测方案

本批72条的所有参考已用于开发讨论，不能成为未见评测。新评测另由不参与训练材料或实现选择的标注任务编写，初步上限60条：普通TN、语境、保留各20条；实际数量以无歧义、无近重复为先，不为凑数拆模板。

新评测作者读取固定政策和覆盖要求；只用训练／验证原文和模板标识作排重，不读取目标、预测或模型选择结果。训练前固定输入、参考、政策及去重记录的哈希；训练入口只能消费不带答案的冻结证明。最终选点后一次比较原文、冻结规则、同提示基座、v1 adapter、v2 adapter。参考有歧义时训练前隔离，运行后发现问题则另存勘误，不追改首轮得分。

分别报告整句匹配、局部转换完成、保留组改动、数量／实体／否定等语义错误、失败与缺失，以及v1→v2的新增成功和退步。人工或助手审阅隐藏方法名，并注明审阅者。测试仍为助手原创合成情境，不称随机盲测、自然评论表现或语音提升。

## 下一次训练与工程边界

沿用原基座revision、任务提示和读法政策，正式v2从原始基座重新初始化LoRA，不接着v1训练；这样不会额外累加v1的训练历程。保留r8／alpha16／dropout0.05、q_proj/v_proj、原优化器与学习率设置。计划仍最多3个epoch／100次更新／2小时／5GiB，外部费用0，任何上限先到即停止；以验证目标token损失选点，不读新评测选模型。

更多数据在相同epoch数下会增加更新次数。因此结果描述为“数据扩充条件下的第二轮比较”，不宣称严格隔离了覆盖与训练步数的因果作用，不据一次结果承诺稳定增益。

现有训练入口硬绑定 `zh-reading-model-v1`、`model-data-v1` 和首轮用途；新首批样例不是这个格式，不伪装v1包绕过检查。正式运行前需为v2添加明确的数据版本消费、来源／目标审阅记录和跨版本隔离验证，同时保持v1可复现。此处的准备完成不表示入口适配、GPU预检、新评测冻结或v2训练已经完成。

立即后续是将首批审阅结论落实为正式数据包并完成最小入口适配，随后准备新冻结评测和一次本地训练。不存在先反复扩规则或先证明TTS收益的额外门槛。
