# 首轮有界中文模型实验 v1：方案与启动条件

日期：2026-10-01。本文补齐中文模型研究方案；尚未准备好本实验训练集、训练入口或权重，未执行训练、付费或发布。已有材料和冻结实验保持原样。

## 研究问题与交付

问题是：在相同输入、任务说明和解码条件下，有限监督微调能否让一个现有小模型更好地学习中文朗读规范化，同时减少正文误改？保持完整中文句子输入、完整规范文本输出；不加入IPA、语音模型、新UI或新骨干架构，不恢复历史越南语任务。

首轮交付是可独立加载的adapter、固定基座与tokenizer清单、训练配置、数据角色与哈希、推理示例、基线对照和失败分析。它是研究实验，不要求先证明全面胜过基线，也不要求先证明整体TTS收益。负面结果可构成完成的研究记录；宣传应用改善、扩大投入与公开发布各有额外证据或权利要求。

v4冻结为现成方案对照，本实验不继续追补其新错例。规则能够解决部分问题并不取消模型实验的研究价值；模型训练成功也不自动证明比规则更有用。

## 输入输出契约

- 推理文件只含`id`和`text`；`id`用于对齐，不进入模型语义输入。模型只看固定任务说明与原文，不看参考、分类、目标跨度、是否需改写、来源组别或审阅备注。
- 输出为同一句子的规范文本。按句内用途展开明确数字；缩写与普通英文单词区别处理；只在明确语境下展开符号。保留原有事实、否定、实体、语气、数量含义以及受保护字面内容。
- 句首回复署名、附加情绪表情和有正文词义的表情分别处理。词义不明时保留原文，不猜隐喻。具体约定须在训练前整理为一份固定标注说明，不以训练或评测输出临时改变。
- 不把所有英文拆成字母，不把所有emoji删除，不将学校编号当普通数量，也不把普通数量一律按编号读。这些是任务边界，不代表当前规则已覆盖所有情况。
- 模型返回解释、附加文字或不同排版时，保留完整输出评分，不事后提取一个看起来正确的答案。空输出、异常、缺失与截断保留记录并计失败。

共享任务提示在数据定稿后、首个训练或对照运行前冻结。未微调基座和微调模型使用同一提示、聊天模板及`enable_thinking=False`设置；提示中不塞入某个评测样本的答案。训练只对目标输出计算损失，提示与输入部分的label设为忽略；参考允许作为训练监督，不允许作为评测推理输入。

## 数据准备与隔离

首轮上限为256条训练、64条验证、64条新固定评测。它们是计划上限，不是已有数据统计；不足时记录实际数量，不为凑数重复或改写评测样本。优先使用有明确项目使用与发布条件的原创中文情境材料，分别覆盖普通TN、语境读法、应保持原样。小样本实验只能说明这种材料上的行为，不能代表真实评论分布。

| 材料 | 可以做什么 | 不可以做什么 |
| --- | --- | --- |
| 新训练集 | 构建监督目标、检查训练损失 | 包含任何评测参考或其改写副本 |
| 新验证集 | 按预定规则选择检查点、诊断有限实现问题 | 加入训练或据其分数反复修改规则后冒充未见测试 |
| 新固定评测 | 最终一次比较基座、微调模型和冻结对照 | 参与词表、提示、训练目标或检查点选择 |
| 已看72条、138条及后续所有已看材料 | 开发诊断、历史回归；用途允许时可显式登记为训练／验证的新版本 | 改称新独立评测，或用于训练后继续宣称原分数独立 |

先按来源、模板和近似表达分组，再划分角色；保存ID交集、精确重复和归一重复检查，以及可疑近重复的人工审查。仅换实体、数字或句式的变体不得跨组。另记录目标形式在训练中已见／未见及组合是否未见，避免把模板记忆称为外域泛化。

新评测由未参与训练样本和实现选择的标注任务准备，参考在训练前固定、隔离；实现者可核验文件哈希，不以参考内容调模型。作者隔离和未用于调参不等于随机盲测；是否同来源、是否助手原创、是否经过用户审核必须分别披露。

训练标签可以来自用途允许、明确重新分配角色的已看材料，不必为了训练全部重新造数据；其先前测试成绩只保留为历史，不能再用于声称训练后的独立效果。每条保留原文、来源或原创声明、标注者角色、参考版本、track及预期局部转换。助手参考必须标为建议：明确内容核对标注说明，歧义项保持待审；不得把TN预测自动当训练真值，本实验不安排对非商业TN的蒸馏。存在参考冲突时先在新数据冻结前解决；运行后才发现的问题进入勘误记录，不覆盖首次参考或分数。

准备数据的入口必须实际读取当前材料审计、逐条参考处置表和勘误，不能只在报告中链接它们。当前记录位于仓库外`E:/CodexRuntime/ReadCue/runs/work-review-2026-10-01/data-audit/`，分别为`data-audit.json`、`reference-dispositions.jsonl`和`reference-errata.json`；冻结时记录所消费版本及哈希，按ID、原案例文件哈希与参考哈希匹配。记录缺失、哈希不符、未知处置、撤回参考或未定标签均拒绝进入训练／验证监督目标，保留拒绝清单；新材料也须先登记同等用途与参考状态。`withdrawn_for_future_use`的旧参考不能因历史已获确认或模型输出相符而恢复使用，待审勘误候选同样不自动成为真值。只有明确复核后的新参考版本、用途和角色登记才可使条目获准使用；旧审计中的`training_ready=false`不能被不留记录地覆盖。数据准备须留出一项针对已撤回第5条旧参考和待审候选的拒绝检查，证实入口执行了该约束。

没有确定参考的评测条目仍进入推理和全批状态统计，EM只在有参考子集计算，并同时给出参考覆盖率、总数与待审数。不得通过移走模型失败或困难样本提高分数。

当前B站档案缺少独立标准数据许可证，不能因其已用于本地诊断就默认可训练并发布权重。数据及基座实际使用权限是启动前需核实的条件；对模型效果的预先证明不是启动条件。数据准备记录须明确本轮能做的研究用途与尚不能承诺的公开发布范围。

## 基座与对照

唯一训练候选沿用本地`Qwen/Qwen3-0.6B`，revision `c1899de289a04d12100db370d81485cdf75e47ca`。加载前核对本地模型清单、文件哈希、tokenizer和模板；缺少文件或版本不符即停止，不自动下载替换模型。

| 对照 | 用途 |
| --- | --- |
| 原文输出 | 测量不处理时的文本匹配及原文保留基准 |
| 未微调Qwen3-0.6B | 与微调模型同提示、输入、模板、解码的主要因果对照 |
| 首轮LoRA模型 | 测量有限监督微调的变化，首先评估裸模型完整输出 |
| 审计修正版纯规则 audit-corrected-v1 | 当前规则对照；撤回误推断并补保护，评测前固定实现和资源哈希 |
| 冻结v4纯规则及规则＋专用TN（可选） | 带已知缺陷的历史系统对照；不单凭胜过它们宣传模型收益 |

审计入口`run_audited_rules.py`只处理规则及校验已有TN候选，不自动运行模型；本次修正不代表已有新的模型对照成绩。

专用TN继续仅作非商业研究对照，不作为训练基座或训练目标生成器。既有旧数据结果可以复用已核验的同一版本产物；新固定评测必须让所有对照实际运行，不能拿不同集合的历史总分比较。

Qwen基座与LoRA共同使用FP16、batch=1、greedy、最多1024个新token、固定seed `20260928`、同一EOS/截断判断和统一计时。此前通用Qwen的随机采样成绩不是这次主要对照，须保留为历史。推理全程离线、`local_files_only`、safetensors，不加载远程自定义代码。

主结果保留裸模型输出；不能给训练模型加规则和回退、却让基座裸跑。若以后研究组合系统，须将原始模型与组合后的结果分别报告，不能把保护回退的收益归于模型学会了保真。

## 评分、保真与归因

继续保留严格整句匹配和现有冻结surface匹配，公式明确为`状态成功且输出匹配参考`。`tn_guard_rejected`等失败的回退即使等于参考，也不计入此完成指标；失败永远留在有参考评测的分母。各数据组和track分别报告，不合并成发音准确率。

首轮同时补充以下离线指标，不能只用整句EM决定改进：

1. **局部目标完成率**：固定参考所标注的数字、缩写、符号等转换单位中，可接受读法的比例；多种合法表示事先记录。对齐不确定时标记待审，不让字符串diff自动决定语义。
2. **新增语义错误**：逐例记录正文删除／臆造、否定或程度改变、实体／英文改变、数量值／单位改变。分别给出错误句数／全部评测句数，以及保留组的错误句数／全部保留组句数；标点或参考未覆盖不自动算语义错误。
3. **改写范围**：目标之外的编辑、受保护字面内容变化、已正确输入变错的案例单列。保留组“逐字符未变”和“语义正确”是不同证据，不能互相替代。
4. **拒绝与交付文本**：报告全批状态、拒绝原因、回退次数，并另算回退后最终文本的匹配情况。该补充指标只描述交付内容，不改变原失败计分，也不冒充模型成功。
5. **配对归因**：基座→LoRA、纯规则→组合分别给出新增匹配、退步和局部错类变化；不能将规则新增覆盖、参考写法选择或输出保护记为训练收益。报告实际样本数与不确定性，不对小批定向样本宣称总体显著改善。

已有guard只检查数字锚点、汉字顺序和显式保护范围，不证明数值或新增文字正确，例如保留“元”并不能排除插入“不收”。本实验以盲去方法名的输出核查补足语义审查，并保留审查者角色、歧义与用户确认范围；助手审查不冒充人耳或用户验收。

TTS可选取有限片段作解释性检查，但不是训练启动或研究完成的门槛。已接受的四段处理后音频和一段原文音频只支持确切产物；波形一致也不能扩大到其他句子或整体收益。

## 启动前清单与完成标准

启动前必须有：固定任务／标注说明；来源用途明确的训练与验证数据；材料审计与勘误的实际消费记录及撤回／待审参考拒绝检查；新评测隔离及哈希；无角色重叠记录；可用环境与模型清单；冻结配置、资源上限和新运行目录。当前这些准备尚未全部完成，现有已看评论不能跳过权利核验和角色登记直接进入训练，更不能改称本实验的独立评测。

有界尝试可因预检或训练失败结束，但这只是失败记录，不等于完成了模型交付或效果实验。完整首轮实验不以胜过规则或TTS提升为条件，而以以下可检查产物为条件：

- 一个成功结束的受限训练运行及完整记录。
- adapter可在指定原基座上重新加载，并有独立加载的推理结果；没有成功权重时明确记录未交付权重，不标为实验完成。
- 按预定方法选点后，一次性运行全部固定对照与新评测，保留原始输出、失败、各组分母、局部错误及配对分析。
- 明确区分工程跑通、已测效果和公开发布条件；负面结果照实保留，不为得到正结果无限补规则或追加运行。

公开HF研究发布另需确认最终数据／基座／adapter条款和可复现材料。现有研究成果可作为基线与经验，不推导中文训练权重已经存在或已经获准发布。
